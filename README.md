## How I work

> **Brief deeply · Map the market · Build the workflow · Keep judgement human · Improve continuously**

I approach recruitment and operations as connected systems. First understand the real decision, then structure the information around it, make the work repeatable where useful, and keep people accountable for the calls that should never be automated away.
